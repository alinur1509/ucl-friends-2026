# Наш турнир ЛЧ 2026/27

Сайт для турнира с друзьями по Лиге чемпионов 2026/27: жеребьёвка команд между 4 участниками, ввод счетов, таблица общего этапа и плей-офф до финала. Изменения сразу видят все, у кого есть ссылка.

Сайт: https://ucl-friends-2026.vercel.app

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | Вся страница: вкладки «Таблица», «Матчи», «Плей-офф», «Жеребьёвка». Календарь 144 матчей — официальный (жеребьёвка UEFA 27.08.2026, время начала по CET). |
| `api/state.js` | Серверная функция Vercel: читает и сохраняет общие данные в Vercel Blob. Проверяет очередь в жеребьёвке и не даёт двум людям забрать одну команду. |
| `package.json` | Зависимость `@vercel/blob`. |

## Как устроено хранение

Все данные лежат одним файлом `ucl-2026-27/state.json` в приватном хранилище Vercel Blob `ucl-friends-2026-data`, подключённом к проекту `ucl-friends-2026`. Переменная `BLOB_READ_WRITE_TOKEN` выставлена в проекте автоматически — в репозиторий её класть не нужно.

## Деплой

Проект на Vercel уже создан. Если подключить этот репозиторий к проекту `ucl-friends-2026` в настройках Git на Vercel, каждый push в `main` будет выкатываться на сайт сам. Фреймворк не нужен: Vercel отдаёт `index.html` как статику, а `api/state.js` — как функцию.
